# Discord 団体統合管理 Bot

Discordサーバー内における所属団体の自動ロール・チャンネル同期、出席ログの記録、およびボイスチャンネルの入退室管理を行うBotです。

---

## 機能概要

- ユーザー自動同期: サーバー表示名（ニックネーム）に含まれる団体名や略称を解析し、該当する役職と専用テキストチャンネルのアクセス権限を自動割り当てします。
- 出席ログ管理: 統合管理パネルのボタン操作により、部長出席・代理出席を即座にデータベースへ記録します。
- VC入退室ログ管理: 指定したボイスチャンネルへの入室・退出時間を記録し、後からCSV形式で出力可能です。
- 定時自動同期: 毎日12:00（JST）にサーバー全メンバーの同期処理を自動実行します。

---

## データベース仕様

本Botは PostgreSQL データベースを使用し、SQLAlchemy ORM 経由でデータを管理します。
起動時にテーブルが未存在の場合は自動で作成されます。
DBの利用には別途設定が必要です。ご留意ください。

### テーブル構成

- `master_org_v16` (団体マスタ)
  登録された団体名、略称、役職・チャンネル作成のスキップフラグを保持します。
- `server_config_v16` (サーバー設定)
  サーバーごとの設定（カテゴリ名、部長役職名、代理役職名、ログチャンネル名、対象VC名）を保持します。
- `attendance_log_v16` (出席ログ)
  ボタン押下時に記録される出席ログ（ユーザーID、表示名、団体名、ステータス、タイムスタンプ）を保持します。
- `vc_history_v16` (VC入退室ログ)
  指定ボイスチャンネルへの入室・退出日時および滞在状況を保持します。

## コマンド一覧

管理コマンドはサーバー管理者権限（Administrator）を持つユーザーのみ実行可能です。

### 1. サーバー設定コマンド

- `!set_config [カテゴリ名] [部長役職名] [代理役職名] [ログチャンネル名]`
  Botが自動作成するチャンネルの格納先カテゴリ、役職名、管理パネル等を配置するログチャンネル名を設定します。
  入力例: `!set_config 団体用 部長 代理 管理ログ`

- `!set_vc [VC名]`
  通話時間や出席状況を記録する対象のボイスチャンネルを指定します。
  入力例: `!set_vc 全体会議`

---

### 2. 団体マスタ管理コマンド

- `!add_orgs [情報]`
  管理対象の団体情報を登録・更新します。改行区切りで複数団体を同時に登録できます。
  引数の順序: `団体名 [略称] [部長役職付与スキップ: true/false] [専用チャンネル作成スキップ: true/false]`
  入力例:
  !add_orgs 吹奏楽部 吹部 false false
  美術部 none false true

- `!del_org [団体名]`
  登録されている指定団体をデータベースから削除します。
  入力例: `!del_org 吹奏楽部`

- `!list_orgs`
  現在登録されている全団体と略称の一覧を表示します。
  入力例: `!list_orgs`

---

### 3. レポート・操作コマンド

- `!panel`
  一括同期、部長出席、代理出席ボタンが付いた統合管理パネルを現在のチャンネルに送信します。古いパネルは自動削除されます。
  入力例: `!panel`

- `!report`
  本日のボタン操作による出席記録（部長出席・代理出席）の集計結果を出力します。
  入力例: `!report`

- `!report_vc`
  指定ボイスチャンネルに参加中のメンバーを団体別に出力します。
  入力例: `!report_vc`

- `!report_reset`
  本日（当日0:00以降）に蓄積されたボタン出席ログをデータベースから削除します。
  入力例: `!report_reset`

- `!export_vc`
  データベースに記録された全期間のVC入退室ログをCSVファイル形式で出力します。
  入力例: `!export_vc`

---

### 4. 一般コマンド

- `!sync`
  コマンドを実行したユーザー自身の表示名を解析し、所属団体の役職付与および専用チャンネルへの権限付与を即座に行います。
  入力例: `!sync`

---

## 動作環境・環境変数

本Botをデプロイして運用する際は、以下の環境変数を設定してください。

- DISCORD_TOKEN: Discord Developer Portalから発行したBotトークン
- DATABASE_URL: PostgreSQLデータベースの接続URL (例: postgresql://user:pass@host/dbname)
- PORT: Webサーバー起動用ポート（デフォルト: 10000）
